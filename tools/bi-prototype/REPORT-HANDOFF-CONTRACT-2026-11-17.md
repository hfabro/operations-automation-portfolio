# Report-to-purchasing handoff

This controller correction protects the shared fictional purchasing journal when a visitor opens the workflow from the business report. It does not change report measures, filters, source models, checkpoint schemas or purchasing rules.

- Current-journal reports retain the exact saved value they successfully loaded. Resuming purchasing checks that value is unchanged, then navigates without writing or normalizing it. An absent current journal stays absent. Changed command content at the same revision, newer progress, deletion and exact-text changes require an explicit report refresh.
- A guided or imported validated checkpoint is a separate replacement context. Any different saved value, including an empty/malformed value, requires confirmation. Visitors can use purchasing recovery to download the retained saved value first. Immediately before saving, the source must still match the value captured before confirmation. Cancellation, drift, or failed storage access preserves the report and all saved journals.
- An exactly matching checkpoint resumes without a redundant save. A confirmed different scenario saves the complete checkpoint, regardless of the report's selected cost center or other filters. Maintenance and work journals are never written by this handoff.
- A validated report import may intentionally recover damaged purchasing data after explicit replacement confirmation. Merely opening an unavailable current source still hides figures and disables handoff; no guided data is substituted automatically.

`node tools/test-bi-report-handoff.mjs` covers 13 source/navigation/recovery groups and four responsive automated accessibility screens per engine. Tests include no-write paths with storage writes forced to fail, stale-current selection preservation, independent guided/imported contexts, confirmation drift, cancellation and successful retry. Existing report browser acceptance covers financial stages, allocations, drill-through and source/export definitions. Everything remains an HTML/CSS/JavaScript simulation; these are bounded browser checks rather than authenticated production concurrency guarantees.
