# Connected BI visitor hub

`preview/showcase.html` is the entry point for the simulated business showcase. It offers four main journeys (machine condition, connected purchasing, BI and work completion), three focused controls (coding, invoice intake, ERP) and a separately labeled historical public-data analysis. Every card is a native link covering its full surface. Brand navigation returns to the hub; historical source/method links retain their original destination.

The current-simulation overview reads validated purchasing/maintenance journals. Empty journals stay empty; invalid journals show unavailable values and preserve stored copies. Reviewed-condition counts use distinct condition IDs, not review-action counts. Paid amounts use the existing allocated financial model. Reading, refreshing and exporting do not mutate either journal.

The evidence bundle contains independently namespaced purchasing, maintenance, work and fictional-machine snapshots, with validated command checkpoints. It does not combine historical public data into fictional company totals, add financial stages as separate purchases, or claim native Power BI. It provides inspectable interview/client evidence without needing live systems.

Eight width/theme screens and 19 browser assertions cover direct routes, native full-card touch navigation without JavaScript, keyboard entry/return, empty/current/invalid journals, accurate counts/paid values, read-only export and expanded methods/accessibility. Desktop/mobile screenshots are retained for visual inspection. The portable runner contains 20 executable groups including all preceding scenarios. Automated accessibility screening does not establish comprehensive conformance.

The nine development pages, including the hub, remain a draft source presentation outside production navigation. Source packaging does not publish them or change the Phase 1 site.
