# Security policy

## Scope

This repository publishes a static professional portfolio. It has no backend, authentication system, production database, payment flow, analytics service, or connection to employer systems. All interactive records are synthetic and remain in the visitor's browser session.

Security reports are welcome for issues in the published portfolio or its delivery workflow, including:

- script or content injection;
- unsafe external navigation;
- unintended disclosure of private or proprietary information;
- exposed credentials or secrets;
- workflow or repository configuration that could alter the published site unexpectedly; and
- bypasses of the documented browser-side restrictions.

The synthetic demonstrations are not production control systems. Reports about fictional records, unavailable production integrations, or intentionally simulated state changes are outside this policy unless they expose a real security weakness in the published site.

## Reporting

Email `hfabro85@gmail.com` with the subject `Portfolio security report`. Include the affected URL, the observed behavior, reproduction steps, and potential impact. Do not include employer information, real credentials, or confidential production data.

Please avoid destructive testing, denial-of-service activity, automated traffic that could disrupt GitHub Pages, or attempts to access accounts or systems outside this repository.

No bug-bounty program, payment, response-time guarantee, or authorization to test third-party systems is offered. Good-faith reports will be reviewed and addressed in proportion to their demonstrated risk.

## Supported version

Only the version currently published from the repository's default branch is supported.
