Analytics architecture

Source alignment comes before the dashboard.

The model joins equipment telemetry and utility context at a deliberate time grain so operating states and demand exposure can be compared without overstating precision.

01 / ingestion

API and JSON

Telemetry must be ingested consistently before utilization or charging logic is credible.

02 / time grain

Interval alignment

Equipment events and utility intervals need compatible timestamps and clearly defined boundaries.

03 / semantics

Governed measures

State of charge, active use, sessions, energy, and cost require documented definitions.

04 / judgment

Decision support

Analytics should surface questions and exceptions—not imply certainty the data cannot support.
